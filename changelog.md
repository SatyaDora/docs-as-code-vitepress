# Changelog

All notable changes to the Surf Weather API are documented here. This project follows [Semantic Versioning](https://semver.org/).

For user-facing app updates, see the [Release Notes](release-notes.md).

---

## v2.0.0-beta — February 2026

### Added

- Beta program opened for API v2
- Planned: extended forecast data and improved response consistency

### Changed

- Improved error messaging structure (beta)

---

## v1.5.0 — January 2026

### Added

- Alert-related fields surfaced for high-wave and strong-wind conditions
- Wind speed data available at hourly granularity

### Fixed

- Location search accuracy improvements for city-name queries

---

## v1.1.0 — October 2025

### Improved

- Response reliability and reduced latency on the `/weather` endpoint

### Fixed

- Intermittent delays when switching between location queries

---

## v1.0.0

- Initial release
- Current weather endpoint added (`GET /weather`)
